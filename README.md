# ћ-скрипт (Ć-Script)

Комични српски програмски језик који се преводи у JavaScript. 🇷🇸

A humorous Serbian programming language that transpiles to JavaScript.

## Здраво свете (Hello World)

```ts
заклето поздрав = "Здраво свете!"
кажи(поздрав)

нека године = 25

ако (године > 18) {
    кажи("Можеш у кафану 🍺")
} иначе {
    кажи("Седи кући")
}

функција поздравиНеког(име) {
    врати "Ћао " + име + ", шта радиш?"
}

кажи(поздравиНеког("Марко"))
```

## Примери

### Класе и наслеђивање

```
класа Човек {
    constructor(име, године) {
        ово.име = име
        ово.године = године
    }

    представиСе() {
        кажи("Зовем се " + ово.име + ", имам " + ово.године + " година")
    }
}

класа Програмер наслеђује Човек {
    constructor(име, године, језик) {
        супер(име, године)
        ово.језик = језик
    }

    кодирај() {
        кажи(ово.име + " кодира у " + ово.језик)
    }
}

заклето горан = прави Програмер("Горан", 30, "ћ-скрипт")
горан.представиСе()
горан.кодирај()
```

### Асинхроно програмирање

```
асинхроно функција направиКафу() {
    кажи("☕ Правим кафу...")
    чекај сачекај(1000)
    кажи("☕ Кафа је готова!")
    врати "турска кафа"
}

асинхроно функција направиДоручак() {
    покушај {
        заклето кафа = чекај направиКафу()
        кажи("Направио сам: " + кафа)
    } ухвати (грешка) {
        кукај("Нешто је пошло по злу: " + грешка)
    } наКрају {
        кажи("🧹 Спремам кухињу...")
    }
}
```

## Грешке на српском

Кад нешто крене по злу, ћ-скрипт ти каже на српском:

| Грешка | Порука |
|---|---|
| `x is not defined` | Брате, "x" не постоји. Јел си заборавио да га направиш? |
| `x is not a function` | "x" није функција, него нека глупост. Провери шта радиш. |
| `Assignment to constant variable` | Брате, заклео си се. Не можеш сад назад. (заклето = const) |
| `Maximum call stack size exceeded` | Бесконачна рекурзија! Ушао си у зачарани круг као кад причаш са таштом. |
| `SyntaxError` | Синтаксна грешка — као да си писао код после треће ракије. |
| `RangeError` | Изашао си из опсега. Као кад наручиш 47. пиво — нема толико. |

## Инсталација

```bash
pnpm install

```

## Употреба

```bash
# Покрени .ћс фајл
ћс покрени здраво-свете.ћс

# Преведи у JavaScript
ћс преведи мој-програм.ћс

# Преведи и сачувај
ћс преведи мој-програм.ћс --излаз програм.js
```

## Развој

```bash
# Инсталирај зависности
pnpm install

# Изгради све пакете
pnpm build

# Покрени тестове
pnpm test

# Покрени тестове у watch моду
cd packages/core && pnpm test:watch
```

## Архитектура

Монорепо са pnpm workspaces + Turborepo.

- **`packages/core`** — Транспајлер, CLI, кључне речи, превод грешака
- **`packages/playground`** — Онлајн игралиште (Vite + Monaco Editor)
- **`packages/vscode-extension`** — VS Code екстензија
